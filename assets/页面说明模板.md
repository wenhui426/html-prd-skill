# 逐页说明模板

此文件只负责默认的单页说明草稿，可复制并改成团队自己的模板；Markdown 文档骨架和 HTML 评审页面分别使用自己的模板。生成页面说明时按实际页面裁剪章节，模板原件保持不变。用户提供自定义逐页模板路径时优先使用；用户指定某一页直接采用其正文时，该页跳过此模板。

```markdown
### PXX 页面名称

**页面目标**

**使用角色与入口**

**页面结构与信息**

**字段与展示规则**

**操作、反馈与跳转**

**页面状态**

**可验证的业务规则**

**数据与权限**

**异常情况**

**与当前 HTML 的差异**

**待确认事项**
```

填写要求：

- 只写有页面、源码或用户材料依据的内容；无法核实的规则放入“待确认事项”。
- 用户确认的目标需求与当前 HTML 不一致时，在“与当前 HTML 的差异”中并列记录。
- 每个待确认事项使用稳定编号，写成用户可以回答的问题，并说明影响范围。
- 页面确认进度由工作流维护，不作为模板固定章节；每页输出时附上当前进度。
- 写入默认 PRD 的“页面需求说明”章时，页面标题使用三级标题；各说明项采用独立的加粗行，不加小节序号。用户指定自由正文时保留用户的标题结构。
